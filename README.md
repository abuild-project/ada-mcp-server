# Ada MCP Server

This repository is the independent abuild-project continuation of
[MDBrothers/ada-mcp-server](https://github.com/MDBrothers/ada-mcp-server).
It retains the selected personal fork's complete history and MIT notices.
abuild-project makes its own maintenance, support and release decisions.

The standalone distribution is **in development**. This initial import is not
a released or fully validated package. The inherited server, container and
client claims require fresh acceptance before this project supports them.
No abuild-project release, container image or PyPI package is available yet.

The selected import is `961f532bcc633189e8618852732be289752cbcd7` from
[the maintained personal fork](https://github.com/mweidle73/ada-mcp-server).
Earlier branch descriptions and plans are historical import records; they do
not define this repository's current workflow. The standalone setup and
validation are being prepared on a separate topic branch.

The server adapts Ada Language Server to the Model Context Protocol. Its own
source remains under the [MIT license](LICENSE); container dependencies keep
their respective licenses.
