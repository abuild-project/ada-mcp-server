# Development roadmap

The first standalone candidate is 0.2.0-rc.1. Complete the documented local
checks, independent review and hosted PR review before merge/release approval.
Public artifact availability, anonymous registry access and a fresh managed
Cloud acquisition test follow a later approved release.

Actual macOS and other native clients are subsequent acceptance topics. Other
fork fixes and upstream proposals are evaluated separately; they are not
silently included in this bootstrap/distribution change.
