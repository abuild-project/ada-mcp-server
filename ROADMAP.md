# Development roadmap

The [first stable 0.2.0 plan](doc/plans/release-0.2.0.md) coordinates reviewed
release preparation and promotion of the exact tested artifacts. Public assets,
anonymous registry access and consumer acquisition need their own direct proof.

Supplied Mac reports cover the bounded accepted implementation described in
the [consumer assessment](doc/assessments/pre-stable-consumer.md). Other native
clients, native-host ALS and broader tool acceptance remain separate work.
A project-build-derived image is a later release recommendation.
