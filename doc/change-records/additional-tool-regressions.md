This topic extends bounded regression evidence to the ten advertised tools
outside the reading probe. It preserves the complete existing CI chain,
dependency pins, prerelease version and documented support limits.

The planned fixture separates actual Ada/GPR inputs and manifest metadata
from owned compiler outputs. Native capability observation and raw protocol
results must precede exact pinned-ALS acceptance where the current behavior
is unknown. Exploration is not semantic acceptance; unsupported methods and
empty positive results remain explicit blockers.

Rename acceptance is limited to explicit preview. The inherited native
`preview=false` path reports application without writing sources; this gap
does not authorize a writer. Formatting returns edits, code actions expose
summary metadata, and Alire reads manifest fields. These checks do not expand
the read-only client policy or the public support contract.

The first frozen phase records capabilities and unaccepted semantic results
through the unchanged server handlers. Its decoded native trace includes
initialize parameters and capabilities, all requested method arguments,
results and re-raised native errors. MCP envelopes, owned input states,
hashes, process births and cleanup evidence are retained separately. This
does not claim a complete native wire or callback transcript. Unexpected
writes or lifecycle failures fail the observation; unsupported or empty
semantic replies remain explicit observations without positive acceptance.

The selected GPR includes source and formatting directories, and an explicit
owned project root also binds requests without a file argument to the same
view. Hierarchy is queried before any source-opening handler, then again
before synchronization after a complete warm source change. The changed
state moves and renames callees, changes formal types/arity and adds a
caller edge. Original valid sources are restored before actual compiler
success/error observations; only owned obj/bin generation is permitted.
