# Ada MCP Server 0.2.0-rc.2

RC2 prepares the public installation and update workflow for this independently
maintained continuation. It retains the Linux/AMD64 Debian Trixie Docker pilot
and the pinned Ada Language Server. Python package metadata and MCP
initialization use `0.2.0rc2`; distribution metadata uses `0.2.0-rc.2`.
Publication is established by the actual non-draft release and verified assets,
not by this source document alone.

- Install directly from public tooling without a private plugin or Plugin
  Creator. Optional local Codex and reader-owned private Cloud skills guide
  the same Docker binding and source-bound queries.
- Receive available-version advisories in initialization and project results.
  Host checks use a private daily cache, a bounded public metadata request,
  opt-out and stable/prerelease policy; installed pins never silently move.
- Ask for a fresh release check immediately. Explicit checks bypass the local
  daily cooldown while respecting actual provider retry deadlines across
  channels. Old advisories become stale and expire even in long-running sessions.
- Let the skill inspect a real target, ask once and execute an approved update:
  verify new artifact pins, stage matching runtime/image/binding/skill/client
  configuration, test real project queries and retain operational rollback.
- Keep verified helper source bytes through client dispatch and isolated update
  fetches. Packaged helpers fail closed on missing declarations; explicit notice
  cache paths are validated before query/configuration output is created.
- Publish these source-reviewed notes with the exact tested artifacts, without
  rebuilding or adding the notes file to the artifact set.

Existing RC1 archives remain immutable and have no update-notice hook. They
need one initial approved upgrade to a published RC2 or later. The
[first-install guide](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.2/doc/first-install.md#install-or-upgrade-to-rc2)
provides a concrete prompt using actual GitHub asset digests, the final release
manifest and exact tag commit. It retains RC1's verified pinned fallback;
never reuse RC1 hashes as RC2 pins. See
[approved updates and rollback](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.2/doc/updating.md)
for activation and provider limits.

The [support matrix](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.2/doc/support.md)
still limits supported semantic queries and diagnostics. Compiler/tests remain
separate. Actual macOS, native Codex/Claude/OpenCode lifecycle and a separate
account's Cloud import remain development work, not inferred acceptance.
The public plugin contains a skill, not native MCP registration or a hosted
service. Publication does not update a private account plugin automatically.

Preserve the original MIT notices and the container components' own terms;
