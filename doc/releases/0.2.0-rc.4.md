# Ada MCP Server 0.2.0-rc.4

RC4 packages the project-view, setup and bounded reading-tool fixes since RC3.
It remains a Linux/AMD64 Debian Trixie Docker pilot with MCP SDK 1.30.0,
pinned ALS/GNAT, workflow contract 1 and the same 19 advertised tools.
Python/MCP metadata uses `0.2.0rc4`; distribution metadata uses `0.2.0-rc.4`.
Actual published release assets establish availability; a source version or
these notes alone does not.

- Retain an explicitly selected importing GPR view for queries anchored to
  its imported sources, including equivalent absolute paths. Shared imports
  use the most recent matching explicit view unless a selected lexical
  ancestor applies.
- Read the existing exact GPR/context by default without reloading or resetting
  readiness. Optional strict Boolean `refresh` defaults to false; use true to
  reevaluate changed source membership on a reused client. A new exact client
  is already fresh and avoids a redundant reload.
- Return valid project metadata independently of pending indexing.
  `complete` describes evaluated metadata; Boolean `indexing_complete` is a
  conservative readiness snapshot. Project selection no longer waits on the
  former 25-second indexing gate. The 30-second ALS RPC timeout and 25-second
  guarded semantic wait remain; follow completeness/truncation results.
- Default new bootstrap bindings to GHCR with a hash-locked archive fallback
  on pull failure/timeout and platform-native cache paths. Preserve existing
  binding sources and explicit overrides; `--transport archive` selects the
  archive route. Successful installs gain an optional local version alias;
  conflicts/errors are reported without replacing aliases or immutable pins.
- Improve bounded dependency summaries for generic units, separate protected
  and task bodies, limited/private context imports, comments, strings and
  quote-character literals; exclude aspects outside context clauses.
- Synchronize a queried source before call-hierarchy evaluation, preserving
  updated file contents in a live session.
- Honor selected-signature parameter precedence, report the effective
  signature index, and preserve malformed selected native indices in separate
  conditional signature/parameter diagnostics with integer-zero fallbacks.
- Reject unsupported rename application explicitly. Preserve native rename
  preview text and legal bare code-action command identifiers without edits.
- Raise optional development minimums to Ruff 0.17.5, pytest-asyncio 1.5.0
  and Mypy 2.4.1; runtime SDK and tool support scope remain unchanged.

Read the selected runtime's verified guide and actual catalog before using
`refresh`; an older compatible entry/runtime does not gain new tool parameters
through workflow contract 1. Compatible RC3-or-later entries can use an exact
verified RC4 runtime without replacement. Legacy RC1/RC2 entries need an initial
entry upgrade for selection. Older published bytes and rollback pins remain
immutable. See the [installation guide](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.4/doc/first-install.md#install-or-upgrade-to-rc4)
and [approved updates](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.4/doc/updating.md).

The [support matrix](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.4/doc/support.md)
still bounds acceptance. Additional tools remain in development; the same
three pinned-ALS positional signature cases remain incorrect and unaccepted.
Compiler/test success is separate from MCP query results. Native Mac and
Codex/Claude/OpenCode fresh installation/lifecycle, plus separate-account Cloud
import, require direct consumer evidence. RC4 publication precedes the planned
clean local Mac Codex/Arca test; a larger-project timing comparison is optional
later work. No Mac/native support or latency improvement is claimed here.
