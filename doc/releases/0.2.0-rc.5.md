# Ada MCP Server 0.2.0-rc.5

RC5 packages the unknown-tool fix, expanded SDK-validation test basis and
shared Codex installation guidance accepted since RC4. It remains a
Linux/AMD64 Debian Trixie Docker pilot with MCP SDK 1.30.0, pinned ALS/GNAT,
workflow contract 1 and the same 19 advertised tools. Python/MCP metadata uses
`0.2.0rc5`; distribution metadata uses `0.2.0-rc.5`. Actual published release
assets establish availability; these notes alone do not.

- Reject an unknown tool name before ALS acquisition or project selection, so
  an ALS connection failure cannot hide the unknown-tool error. Preserve the
  JSON error convention, tool context and catalog hint. A defensive dispatch
  fallback now identifies an advertised tool with no handler accurately.
- Pin the locked SDK's existing input-validation boundary through real stdio
  rejection/startup controls and bounded real-ALS integration checks. Invalid
  advertised arguments are rejected before server dispatch; allowed extra
  properties remain allowed. This expands regression evidence without changing
  schemas, the SDK, dependencies or supported behavior.
- Package once-per-user Codex skill/native setup guidance for multiple Ada
  repositories and actual client-managed worktrees. Keep GPR/search paths and
  scenarios explicit per connection, approve the physical parent roots, merge
  native configuration explicitly and preserve rollback state. Clarify clean
  acquisition, the existing GHCR default/archive fallback and Desktop reconnect
  checks. Older published archives and installed skills retain their bytes.

Compatible RC3-or-later selection-aware entries can use an exact authenticated
RC5 runtime without replacement. Check actual publication and new target pins
before acquisition; retain the previous runtime/binding/image and selection
backup for rollback. See the [installation guide](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.5/doc/first-install.md#install-or-upgrade-to-rc5)
and [approved update procedure](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.5/doc/updating.md).

The [support matrix](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.5/doc/support.md) remains unchanged in scope. The supplied
[Mac/Codex assessment](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.5/doc/assessments/macos-codex-rc4.md) is historical RC4
evidence. RC5 publication enables a subsequent Mac update-path test; this
package does not establish that acceptance. Other client/platform limits and
the three unaccepted pinned-ALS positional signature cases remain. Preserve
the MIT and component notices under [licensing](https://github.com/abuild-project/ada-mcp-server/blob/v0.2.0-rc.5/doc/licensing.md).
