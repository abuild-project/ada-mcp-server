# Ada MCP Server 0.2.0-rc.6

RC6 packages the host Python and update-policy fixes accepted since RC5. The
pilot uses Linux/AMD64 Debian Trixie Docker, the locked MCP SDK 1.30.0, the
existing ALS/GNAT pins, workflow contract 1 and the same 19 advertised tools.
Python package and MCP server metadata report `0.2.0rc6`. The published assets
and their authenticated metadata establish availability.

- New native Codex fragments pin the setup process's supported Python 3.11+
  interpreter and record the effective update channel and its source. Older
  fragments can still use their own PATH. Preserve an intentional opt-out,
  review the generated fragment and merge the intended Ada entry explicitly.
- Offline Doctor and launcher `--check` validate an enabled advisory's Python
  and reject invalid policy. The version probe validates the complete response
  and has an independent two-second budget. Normal startup and queries remain
  usable after advisory failures, with bounded stderr diagnostics and protocol
  stdout preserved. An invalid inherited channel disables only the advisory.
- The installation guide covers Mac/Codex native setup and the separate private
  Managed Cloud entry. On Cloud, activate the plugin, verify discovery and
  resolve or acquire an authenticated runtime before Docker-backed queries.
  The skill plugin supplies instructions and helpers. Cloud queries use those
  helpers instead of direct native registration.

After publication, verify the exact RC6 pins before installation or upgrade.
Compatible RC3-or-later entries can retain their version and select the RC6
runtime. Keep the prior runtime, binding and selection backup for rollback.

supplied Mac assessment covers RC4, and later RC5 observations document a
scoped PATH correction and a cached notice. Existing client/platform limits
and the three unaccepted pinned-ALS positional signature cases still apply.
