# Ada MCP Server

Use Ada MCP to explore your Ada code from an assistant or terminal. Select
your project file (`.gpr`) to list symbols, find definitions, see type
information, or inspect diagnostics for a file.

## Get started

- [Set up Codex Desktop on a Mac](first-install.md#mac-with-codex-desktop).
- [Set up Codex in Managed Cloud](first-install.md#codex-in-managed-cloud).
- [Set up the Docker query helper](first-install.md#direct-docker).

Once connected, try this with a project and file from your checkout:

> Select `app.gpr` and list the symbols defined in `src/app.ads`.
> Give me the file names and line numbers.
